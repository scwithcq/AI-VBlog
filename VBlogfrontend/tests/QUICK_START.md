# 快速开始测试指南

## 🚀 5 分钟快速测试

### 步骤 1: 启动后端服务

```bash
# 确保后端 Spring Boot 应用正在运行
# 默认端口: 8080
```

### 步骤 2: 获取测试 Token

**方法 A: 从浏览器获取 (推荐)**

1. 打开前端应用 http://localhost:5173
2. 登录账号
3. 按 F12 打开开发者工具
4. 进入 Application 标签页 → Session Storage
5. 找到 `token` 项，复制其值

**方法 B: 使用 API 登录获取**

```bash
curl -X POST http://localhost:8080/api/user/login \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=your_username&password=your_password"
```

### 步骤 3: 打开测试工具

1. 双击打开 `tests/api-test.html`
2. 或在浏览器中输入文件路径

### 步骤 4: 配置测试参数

在页面顶部填入：

- **JWT Token**: 从步骤 2 获取的 Token（不含 "Bearer " 前缀）
- **测试用户 ID**: 另一个测试用户的 ID（用于好友关系测试）
- **API 基础 URL**: `http://localhost:8080/api` (默认值)

### 步骤 5: 运行测试

点击页面中的 **"运行所有自动测试"** 按钮

### 步骤 6: 查看结果

- 顶部卡片显示测试统计
- 控制台区域显示详细日志
- 绿色 ✅ 表示通过
- 红色 ❌ 表示失败

## ⚠️ 常见错误及解决

### ❌ 错误: 请先配置 JWT Token

**原因:** 未填写或 Token 格式错误
**解决:** 在页面顶部填入有效的 JWT Token

### ❌ HTTP 401: Unauthorized

**原因:** Token 无效或已过期
**解决:** 重新登录获取新的 Token

### ❌ HTTP 404: Not Found

**原因:** API 端点不存在或后端未启动
**解决:**

- 检查后端服务是否运行
- 确认 API URL 配置正确

### ❌ 请求异常: Failed to fetch

**原因:** 网络连接失败或 CORS 问题
**解决:**

- 检查后端服务状态
- 确认 CORS 配置允许前端域名
- 检查防火墙设置

### ❌ WebSocket 连接失败

**原因:** WebSocket 端点未启动或配置错误
**解决:**

- 确认后端 WebSocket 配置
- 检查 URL: `ws://localhost:8080/ws/message`
- 查看后端日志

## 💡 测试技巧

### 1. 准备测试数据

- 创建至少 2 个测试账号
- 确保账号间有好友关系
- 发送几条测试消息

### 2. 逐步测试

建议按以下顺序测试：

1. 先测试好友系统（搜索、申请、列表）
2. 再测试消息系统（会话、发送、接收）
3. 最后测试 WebSocket 实时功能

### 3. 查看详细日志

- 点击每个测试按钮可单独测试
- 控制台会显示完整的请求和响应
- 失败时会显示详细错误信息

### 4. 清空日志

点击"清空日志"按钮可清除控制台输出，便于重新测试
