## 🔍 常见问题排查

### 1. Token 验证失败

**错误表现:** 所有 API 返回 401 或 403
**解决方案:**

- 检查 Token 是否过期
- 确认 Token 格式正确（Bearer Token）
- 重新登录获取新 Token

### 2. WebSocket 连接失败

**错误表现:** 控制台显示 WebSocket 错误
**解决方案:**

- 确认后端 WebSocket 端点已启动
- 检查 URL 是否正确: `ws://localhost:8080/ws/message?token={token}`
- 检查防火墙设置
- 查看后端日志

### 3. 用户信息获取失败

**错误表现:** 会话列表显示"未知用户"
**解决方案:**

- 检查 `/user/info/{userId}` 接口是否正常
- 确认数据库中用户数据完整
- 查看后端日志

### 4. 会话列表为空

**错误表现:** 消息页面显示"暂无会话"
**解决方案:**

- 通过好友列表选择好友开始聊天
- 检查 `/message/conversations` 接口返回
- 确认当前用户有好友关系

### 5. 消息发送失败

**错误表现:** 点击发送后无响应或报错
**解决方案:**

- 检查消息内容是否为空
- 确认选中了会话
- 查看网络请求返回的错误信息
- 检查后端消息接口
