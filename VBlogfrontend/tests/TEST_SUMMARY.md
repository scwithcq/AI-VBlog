## 🚀 快速开始

```bash
# 双击打开 api-test.html
# 或在浏览器中访问
file:///path/to/api-test.html
```

### 步骤 2: 配置参数

```
1. JWT Token: 从登录后的 localStorage 获取
2. 测试用户ID: 填入要测试的目标用户ID（默认2）

```

```

```

```
- 控制台区域显示详细日志
- 绿色表示成功，红色表示失败
```
